# Xandora 3D Website Module Image Pack

This prompt pack is for generating polished 3D website visuals that give visitors a quick snapshot of the Xandora platform.

## Visual Direction

- Style: premium 3D product illustration, isometric, glossy, futuristic, enterprise software aesthetic
- Brand palette: deep navy, cyan, electric blue, violet, soft white highlights
- Mood: confident, modern, high-tech, clean, premium
- Lighting: cinematic studio lighting with soft glow accents and subtle rim light
- Surface language: glass panels, polished metallic trims, glowing UI edges, subtle depth shadows
- Background: transparent background preferred for website placement
- Avoid: people, photos, clutter, watermark, text blocks, random logos, low-detail shapes, cartoon look

## Export Targets

- Format: PNG
- Background: transparent
- Size: 1200 x 1200
- Composition: centered object with comfortable padding
- Use: feature cards, homepage sections, product snapshots, service highlights

## Global Style Prefix

Use this style prefix before each prompt if your image generator works better with one shared base style:

```text
Premium isometric 3D software illustration for Xandora, transparent background, dark navy and cyan enterprise tech palette with blue-to-violet glow accents, polished glass UI panels, subtle metallic material, cinematic studio lighting, soft reflections, clean composition, modern SaaS product visual, high detail, premium website asset, no text, no watermark.
```

## Best Generator Settings

- Ask for transparent background if supported
- Keep the prompt focused on one object cluster per image
- If the result feels too generic, add: `more premium enterprise SaaS aesthetic, less game-like`
- If the result becomes too busy, add: `simplified composition with one hero object cluster`
- If you want a more realistic product-ad style, add: `closer to product render than concept art`

## Recommended Website Usage

- Use the hero image on the homepage banner
- Use the module images on feature cards
- Keep all module images the same size for consistency
- Add subtle hover lift or glow in CSS instead of editing the image itself
