# Xandora Pricing Sheet Rewrite

## Recommended Packaging Direction

Keep `Retail` and `Stock Take` as separate paid modules.

The key is to make `Retail` clearly sales and POS focused, while `Stock Take` owns inventory counting, audits, and reconciliation. That avoids overlap and makes the upsell easier to justify.

## Ready-to-Use Pricing Copy

### XANDORA
RFID-Based Smart Operations Platform

### Overview
Xandora is a modular RFID-enabled software platform built to improve retail operations, inventory accuracy, and asset lifecycle visibility across stores and industrial environments.

### Core Platform License
Includes the central dashboard, device integration, real-time data streaming, admin controls, API layer, and reporting foundation.

Pricing: `LKR 1,000,000 - 1,500,000` one-time

### Operational Modules

| Module | Description | Price |
| --- | --- | --- |
| Retail | Billing workflows, POS validation, and retail item movement verification | `LKR 250K - 400K` per store |
| Stock Take | Inventory counting, audits, variance checks, and reconciliation workflows | `LKR 200K - 350K` per store |
| Laundry | Item lifecycle tracking, usage history, and status monitoring | `LKR 200K - 300K` per location |

### RFID Device Scaling
First 2 readers per store included. Additional readers: `LKR 5,000 - 10,000/month` or `LKR 25,000 - 50,000` one-time.

### Mobile Application
Handheld scanning, sync, and operational task execution.

Pricing: `LKR 40,000 - 75,000` per device

### Support & Maintenance
AMC: `LKR 30,000 - 80,000/month` depending on deployment scale.

### Pilot Package
1 store bundle including Core Platform, Retail Module, Stock Take Module, and 2 readers.

Pricing: `LKR 800,000 - 1,200,000`

### Positioning
Xandora is a modular RFID operations platform that lets customers start with the workflows they need today and add more operational modules as they scale.

## Shorter Retail/Stock Take Version

If you want the table descriptions to be even sharper:

- `Retail`: Billing, POS validation, and store-floor item verification
- `Stock Take`: Inventory counting, audits, and reconciliation

## Sales Note

If a customer asks whether inventory is included in `Retail`, the safest answer is:

`Retail covers sales-side validation and store operations. Stock Take is the separate inventory module for counting, audits, and reconciliation.`
